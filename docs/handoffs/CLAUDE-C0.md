## 3. Integration design (what to review)

- **Packaging.**
  - `implementation(project(":bridge-java"))` for compile and dev runtime.
  - `tasks.jar` merges the bridge JAR's classes plus `META-INF/ooze/**` plus `natives/**` once, with `DuplicatesStrategy.FAIL`.
  - There is **no** `include` (jar-in-jar) and no second mod ID, and `NativeBindings` is not relocated.
  - The JAR has one `fabric.mod.json` and no duplicate entries.
- **Native resources.**
  - `-PoozeNativeResources=<absolute dir>` (Sol's property) supplies the prebuilt DLL and manifest.
  - Without it the mod still builds. The root `build.gradle.kts` disables Sol's `verifyNativeArtifact` and `bridgeContractTest` **only** when resources are absent or the host isn't Windows x64, and logs why. This is integration glue; finding S-2 asks Sol for an in-module switch.
- **Loading.**
  - `BridgeEngineConnector.connect()` calls `NativeLoader.tryLoad(<gameDir>/.ooze/natives)` on the render thread during client init.
  - `BridgeStatusMapper` maps `LoadResult` to the TARGET_PLATFORM §5 states.
  - The mapper is tested against Sol's exact G0 strings, with a **drift guard** that reads Sol's `NativeLoader.java`.
- **Gating.**
  - `EngineGate` registers nothing Ooze-branded unless the engine is `LOADED`.
  - The developer F9 key exists only in development **and** with `LOADED`.
  - Release runs ignore developer fault injection.
- **Developer fixture** (G0 step 5). `BridgeDiagnosticScreen`:
  - creates a `DEV_FIXTURE` `EngineSession` on the render thread in `init()` and closes it in `removed()`;
  - each frame, encodes one `InputBatch` (resize with the DESIGN_SYSTEM §9.1 UI scale, pointer move in physical pixels using framebuffer ÷ window scaling, button 0 press and release) and makes one `submit`;
  - makes one `renderFixture` into a pooled `FrameBuffer`;
  - **eagerly copies** the 6 vertices (px → GUI ÷ `guiScale`; ARGB numeric = `setColor(int)`) and closes the lease, then submits a `FixtureRenderState` (`GuiElementRenderState`, vanilla `RenderPipelines.GUI`, triangles as degenerate quads) through `GuiGraphicsAccessor`;
  - on any bridge failure, closes the session and shows the reason; Minecraft continues.
- **Mixin.** `GuiGraphicsAccessor`, a read-only `@Accessor` for `GuiGraphics.guiRenderState` (package-private in 1.21.11; Fabric API doesn't widen it). Config `required: false`, `defaultRequire: 0`. Launch tests assert it applies in both dev and production.
